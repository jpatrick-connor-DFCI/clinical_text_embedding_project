**Figure X. Clinical text embedding, endpoint prediction, and manuscript analysis workflow.**

**a, Patient representation.** Clinician notes, imaging reports, and pathology reports recorded strictly before first treatment are encoded individually with pretrained Clinical ModernBERT. Token representations are mean-pooled to produce a 768-dimensional embedding for each note. Within each patient and note type, note embeddings are combined using a recency-weighted mean, with normalized weights proportional to exp(−λΔt), where Δt is the number of days from the note to the prediction anchor. The baseline prediction pipeline uses λ = 0.01 per day. The three pooled vectors are concatenated into 2,304 text features; patients must have all three note types. Colors identify note types throughout panel a. The increasing dot sizes beneath the note vectors denote greater weight for more recent notes. First treatment defines baseline time zero, and subsequent clinical events provide the prediction outcomes.

**b, Endpoint prediction.** The shared patient representation enters separate elastic-net Cox models for individual endpoints in the mortality/metastasis, three-character ICD-10, four-character ICD-10, and PhecodeX schemes. Models include age, sex, and cancer type; the text feature set also includes two note-era covariates (the fractions of imaging and pathology notes predating 2015). Follow-up time and event indicators account for censoring. Model development and evaluation use separate patient partitions; held-out patient risk scores for the penalized text model use nested cross-validation, with hyperparameter selection confined to the corresponding training partitions. The fold diagram is schematic. Each column of the illustrated score matrix denotes a separate endpoint; related endpoints across coding schemes are not mutually exclusive, and eligibility can differ by endpoint. Baseline pooling is performed once and reused across endpoints.

**c, Main manuscript analyses.** Predictive-performance analyses compare text with the age/sex/cancer-type base model using held-out Harrell's concordance index (C-index), summarize endpoint-level differences, and assess overall-survival stratification by stage and text-risk quartile. Pooled models are additionally evaluated within cancer types. Complementary-information analyses compare text with stage, treatment, somatic genomic features, polygenic risk scores (PRS), and metastatic burden using modality ranks, joint Cox associations, and combined models. The longitudinal extension updates note pools at successive monthly landmarks and applies a fixed baseline mortality model to characterize rising, stable, and falling risk and their associations with landmark-conditional survival. This extension uses notes available before each landmark and its separately configured decay parameter (λ = 0.1 per day); it does not reuse the baseline note window unchanged. Note marks, embedding values, score matrices, and mini-plots are illustrative and do not depict study results.
